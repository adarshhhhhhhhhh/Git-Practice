# Git-Practice

Welcome to **Git-Practice**! 🚀

This repository is created to gain hands-on experience with **Git and GitHub** and understand how version control works in real-world software development.

The main goal of this project is to practice essential Git commands, learn how to manage code changes, and become comfortable working with repositories.

## 🎯 Objectives

* Learn the fundamentals of Git and GitHub.
* Understand how to initialize a Git repository and track files.
* Practice staging, committing, and managing changes.
* Learn how to check repository status and view commit history.
* Understand how branches work and how to switch between them.
* Practice connecting a local repository to GitHub.
* Learn how to push and pull changes between local and remote repositories.
* Get familiar with writing meaningful commit messages.
* Explore how to manage project files and maintain a clean repository.

## 🛠️ Tools and Technologies

* **Git** – For version control and tracking changes.
* **GitHub** – For hosting repositories and managing projects online.
* **Visual Studio Code** – For writing code and using the integrated terminal.
* **Markdown** – For documenting the project and practicing README files.

## 📚 What I'm Learning

Through this repository, I'm exploring how developers track their progress, maintain a history of their work, and collaborate efficiently using version control.

I'll be experimenting with different Git commands, making changes to files, creating commits, and learning from mistakes along the way.

## 💻 Basic Git Workflow

The basic workflow I'm practicing is:

1. Initialize a repository using `git init`.
2. Add files to the staging area using `git add`.
3. Save changes with `git commit`.
4. Check the current status using `git status`.
5. Review previous commits using `git log`.
6. Connect the local repository to GitHub.
7. Upload changes using `git push`.
